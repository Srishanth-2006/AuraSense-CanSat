AuraSense: Intelligent Edge-Computing CanSat
AuraSense is an advanced environmental monitoring platform that transforms the traditional "CanSat" — a soda-can-sized sensor module — into an active, intelligent monitoring unit. By leveraging edge computing, the system performs real-time sensor fusion and predictive analytics to detect pollution trends and anomalies instantly.

🚀 Key Features
Edge Intelligence: The flight module calculates a standardized Air Quality Index (AQI) on-device using a calibrated model for immediate atmospheric insights.

Predictive Analytics: The ground station implements a "learning phase" to establish a statistical baseline, enabling autonomous detection of environmental anomalies.

Low-Latency Telemetry: Uses the ESP-NOW protocol for stable, power-efficient, peer-to-peer communication, bypassing the overhead of traditional Wi-Fi stacks.

Real-Time Dashboard: A Flask-based web server serves an interactive UI with live data visualization and AI-driven status insights.
